# Drop Network 0.0.85

- Renamed the primary OTP provider to Messavo, with `woven` retained as a
  one-release configuration alias.
- Added stable provider idempotency keys, persisted Messavo job IDs, safe
  delivery-status polling, and cancellation for replaced or expired queued OTPs.
- Invalidated failed and cancelled challenges and added accessible resend states
  throughout registration, recovery, request ownership, and listing removal.
- Removed console OTP logging and made missing delivery configuration fail closed
  in every environment.

Production requires a private Messavo automatic-send key. Existing provider
settings using `woven` remain compatible for this release.
