# Drop Network 0.0.87

Released: 2026-08-26

## Changed

- Expanded required after-call outcomes with call-back-later, no-answer,
  switched-off/unreachable, wrong-number, declined, and not-called choices plus
  structured decline reasons.
- Added public, non-accusatory contact-issue counts from distinct verified
  requesters after real recorded phone reveals. Reporter identities and notes
  remain private.
- Added automatic search suppression after three independent wrong-number or
  unreachable reports within 90 days for registered and imported donors.
- Added the owner Contact reports inbox with Messavo phone reverification,
  corrective profile remediation, and private disputes.
- Added staff aggregation, abuse-pattern, suspension, restoration, dispute, and
  audit controls. Resolutions append stale markers instead of deleting evidence.
- Preserved imported contact-suspension state across datastore migration and
  donor re-import.

## Compatibility and operations

- Existing call-report rows remain valid; new categories are additive.
- The imported table receives the restart-safe `contact_state` column and row
  schema v4 backfill. Suspended records remain claimable but are excluded from
  search and phone reveal.
