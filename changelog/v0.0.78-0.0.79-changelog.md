# v0.0.78 to v0.0.79

- Prefills a new donor's home district and upazila from the active search while keeping both fields editable.
- Removes public imported-list browsing and routes donor discovery through scoped search only.
- Adds 24-result search pages and an in-memory daily budget per account and IP: three districts, three blood groups, and nine unique searches. Paging the same search does not count again.
- Keeps opaque ownership claims, self-service removal, masked results, one-at-a-time contact reveals, and the standard API rate limit unchanged.

No migration or configuration change is required. The daily search budget resets at Dhaka midnight and, like the existing in-memory limiters, resets when the server process restarts.
