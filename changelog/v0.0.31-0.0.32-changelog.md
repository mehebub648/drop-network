# v0.0.31 → v0.0.32

Functionality and UX upgrade, modeled on established blood-donation platforms.

## Matching

- Donor matching is now compatibility-aware: a request also matches donors of
  every medically compatible group (e.g. A+ patients see A+, A-, O+, and O-
  donors), instead of exact-group-only. Results are de-duplicated and still
  sorted by distance.

## New features

- `GET /api/stats` — public network counts; shown live on the landing page.
- Live Requests feed: blood group, district, and urgent-only filters; urgency
  badges (Critical / Urgent / Scheduled from the needed-by date); urgent-first
  sorting; result counts; comment counts; loading skeletons.
- Request detail: urgency badge, compatible-donor-groups strip, and share
  actions (WhatsApp share + copy link with prefilled message).
- Donor profile: eligibility card — 90-day countdown since the most recent
  known donation with a progress bar, and an availability nudge once eligible.
- Landing page: live stats band, full blood-compatibility chart, and a
  donor-eligibility FAQ.

## Internals

- New `src/lib/blood.ts` with compatibility maps, urgency, and eligibility
  helpers; the server mirrors the compatibility map in `server/server.ts`.
