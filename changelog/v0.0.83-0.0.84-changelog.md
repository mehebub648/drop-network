# v0.0.83 to v0.0.84

- Removed the fixed startup row ceiling, indexed sessions by token, and moved
  audit reads out of the boot path.
- Added strict origin checks for signed-in mutations, protected production
  metrics, and made readiness require SMS, disabled OTP bypass, and monitoring
  protection.
- Upgraded to security-fixed React, React Router, and PostCSS releases, repaired
  navigation typing, made secret scanning full-history, and split the
  administration and donation-history routes from the entry bundle.
- Changed the default production canonical origin to the current hosted HTTPS
  address. Future domain replacement remains configuration-only through
  `APP_URL`.

Production now requires Node 22.22 or newer and a private `METRICS_TOKEN` of at
least 32 characters.
