# v0.0.28 to v0.0.29 Changelog

## Production hardening

- **Removed demo data.** Deleted the generated demo donors/requests, the
  `BD_LOCATIONS` table, and the `SEED_DEMO_DATA` / `DEMO_SEED_PASSWORD` seeding
  path. The datastore now starts empty in every environment and is populated
  only by real activity (`server.ts`).
- **Configurable datastore path.** `db.ts` now reads `LANCEDB_PATH` and falls
  back to `./.lancedb` for direct local runs.

## Volume mapping

- Docker now stores LanceDB under a dedicated `/data/lancedb` directory backed
  by the `drop_lancedb` / `drop_lancedb_dev` named volumes, instead of mixing
  data into `/app`.
- The production image creates `/data/lancedb` and runs as the unprivileged
  `node` user so the mounted volume is writable without root.

## Config & docs

- `.env.example`: dropped the demo seed variables, added `LANCEDB_PATH`.
- Added `.lancedb/` to `.gitignore`.
- Updated `ARCHITECTURE.md`, `README.md`, and both deployment guides for the new
  storage path, volume mounts, and empty-by-default datastore.
