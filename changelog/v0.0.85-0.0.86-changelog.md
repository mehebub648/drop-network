# Drop Network 0.0.86

Released: 2026-08-26

## Changed

- Added stable, collision-checked 12-character `/c/:slug` claim links and kept
  old opaque directory links as redirects.
- Rebuilt claiming around editable-phone Messavo verification and explicit
  owner confirmation. Matching phones claim the imported stub; different
  unique phones create or update a separate passwordless donor profile.
- Added privacy-preserving anonymous donor suggestions at `/contribute` with no
  intake SMS, no publication before owner consent, neutral duplicate responses,
  abuse controls, and 30-day expiry.
- Made imported-donor migration and refresh preserve claim links, ownership,
  withdrawals, publication state, and contribution state by public ID.
- Added OTP sign-in for passwordless accounts created through claiming.

## Compatibility and operations

- Existing long claim links and the legacy authenticated claim API remain
  available for one release.
- The imported table receives additive, restart-safe columns and a deterministic
  slug backfill. Run the importer with `--dry-run` and compare preserved-state
  counts before a production refresh.
- No legacy account datastore is mounted or migrated.
