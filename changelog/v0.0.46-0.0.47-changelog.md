# v0.0.46 to v0.0.47

## Changed

- Made an unconfigured OTP channel use console delivery automatically in
  development and test environments.
- Generated OTPs with a cryptographically secure integer source.
- Invalidated newly created challenges when persistence or delivery fails so a
  failed attempt does not create a false cooldown.

## Configuration

- Production still requires a complete HTTP SMS provider configuration and
  never falls back to console output.
- An explicitly selected but incomplete HTTP provider fails closed.
