# Drop Network 0.0.124

- Simplified Requests to a title, result count, filter button, and divided list;
  the page-specific promotional footer is no longer shown.
- Applies signed-in profile blood group and district as initial filters when no
  shareable URL filters are present.
- Adds oldest-first 20-request pagination and a quieter, proximity-ranked
  “Other emergency blood” section when fewer than ten exact matches exist.
- Rebuilds the landing page around donor search while retaining compact live
  network activity, urgent-request access, and expandable safety, privacy, and
  donation guidance.
- Replaces horizontal mobile account navigation with an accessible section
  sheet and removes oversized promotional footers from task and account routes.
- Keeps all donor-profile fields while grouping optional preferences, health,
  and donation history into collapsible sections with a persistent Save action.
- Adds a compact contents navigator to information and legal pages, simplifies
  community publishing, and provides a first-paint Android app layout without
  duplicated website chrome.
- Refreshes the Browserslist toolchain data to resolve the release audit gate.
