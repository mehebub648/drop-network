# v0.0.49 to v0.0.50

## Changed

- Replaced the unfinished green brand palette with an accessible blood-red
  visual system across the site chrome, public pages, operations workspace,
  PWA metadata, and app icon.
- Removed the externally hosted font request that production security policy
  blocked, improved mobile navigation, short-screen authentication, request
  list errors, filter labels, pagination labels, icon-field spacing, and
  320-pixel layout wrapping.
- Made the blood collection facility and full address explicit when creating,
  reviewing, viewing, and editing a request.
- Added 198 optional facility suggestions from the supplied DGHS export,
  restricted to records officially categorized as `Blood Bank`.

## Safety and compatibility

- Registry suggestions are category-filtered reference data, not proof of
  current service availability. Requesters must confirm collection, screening,
  and transfusion arrangements directly with the receiving facility.
- Manual facility entry remains supported, and existing requests remain
  compatible without a data migration.
