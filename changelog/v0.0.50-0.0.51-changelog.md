# v0.0.50 -> v0.0.51

## Landing page counts the whole network

The landing page reported only registered accounts with a donor profile, so it
showed `1` while the imported directory held about 130,000 records.

- `GET /api/stats` now returns `donors`, the headline count of everyone findable
  here: registered donor profiles plus unclaimed imported listings. Claimed
  listings are counted once, as registered profiles.
- The response also breaks the headline into `directory_donors` and
  `registered_donors`.
- If the imported table cannot be read, `donors` and `directory_donors` are
  `null` and the landing tile renders a dash instead of a count that silently
  omits the directory.
- The first landing tile now reads **Donors** instead of **Registered donors**.

## A phone number is mandatory for imported donors

A listing nobody can call is not a usable donor, and the number is also the
dedupe key that recognises the same person across sources.

- `scripts/import-donors.ts` rejects any scraped record without a valid
  Bangladesh mobile number instead of blanking the field.
- Opening the `imported_donors` table deletes rows stored before this rule, so
  existing datastores are cleaned once rather than filtered on every query.
- 751 phone-less rows were removed from the production store, leaving 129,467
  contactable donors. Most came from the Quantum Method listing, which publishes
  no phone numbers.
