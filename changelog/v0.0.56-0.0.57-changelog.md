# v0.0.56 -> v0.0.57

The home page and donor directory now read as one responsive three-step journey:
Search area, Choose donor, and Confirm & call. Search criteria carry into a
compact directory summary, where they can be refined without covering or
leaving the result workflow.

The redesign also clarifies which details stay private, prevents older request
IDs from being reused after criteria change, keeps shared search URLs from
opening contacts without their missing request context, and removes mobile
result-card overflow and duplicate footer-key warnings.
