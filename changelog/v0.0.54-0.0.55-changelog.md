# v0.0.54 -> v0.0.55

Registered donors can now report an exact last-donation date, an approximate
number of days, months, or years ago, or that they have never donated, together
with a lifetime donation count. The same guided fields are available during
registration and in the donor profile, and the bounded self-reported summary is
shown on registered search results when available.

Detailed donation records and collection-organization names remain private.
Existing profiles that only contain a legacy last-donation date continue to
work without migration.
