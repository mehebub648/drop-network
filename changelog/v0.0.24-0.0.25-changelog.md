# v0.0.24 to v0.0.25 Changelog

- Removed the fixed `123456` OTP bypass and replaced it with short-lived generated OTPs.
- Added a pluggable SMS provider layer (`sms.ts`). When no SMS gateway is configured, the `123456` fallback OTP is accepted again for testing; once a provider is wired up via `SMS_PROVIDER`, only the real generated OTP is accepted.
