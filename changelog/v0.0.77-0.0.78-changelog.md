# Drop Network 0.0.78

- Require every new account to create a donor profile with a valid blood group,
  location, and explicit availability choice.
- Replace the optional age, weight, and donation-history onboarding form with a
  short available/not-available choice; those details remain editable later.
- Add “I’m not available to donate” with a private optional reason that can be
  updated from the donor profile and is never shown in donor search.
- Existing accounts and donor records require no migration.
