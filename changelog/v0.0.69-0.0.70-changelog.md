# v0.0.69 to v0.0.70

- Ask third-party coordinators for their own account contact and the patient's
  or relative's contact as two clearly separate numbers.
- Carry the coordinator's number into OTP verification and account registration
  while keeping it editable before a code is sent.
- Keep the patient-side number limited to the blood request payload and show both
  numbers as distinct entries during review.
- Reuse a signed-in member's verified account number instead of asking for it
  again, and prefill the account name from the request details.

No API, datastore, configuration, or migration change is required.
