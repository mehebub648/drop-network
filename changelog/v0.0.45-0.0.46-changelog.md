# v0.0.45 to v0.0.46

## Changed

- Added public search for verified, eligible, opted-in registered donors.
- Kept donor phone numbers out of guest responses and revealed them only to
  signed-in active members.
- Separated the always-masked imported archive from live donor discovery.
- Replaced phone-derived imported URLs with opaque public IDs and restricted
  claimed records to their claimant or authorized staff.

## Migration and compatibility

- Existing imported rows receive a non-destructive `public_id` column backfill
  on first access. Storage IDs and claim state are preserved.
- `/directory/:id` remains as a compatibility alias for imported detail links.
