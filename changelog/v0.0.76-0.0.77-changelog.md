# Drop Network 0.0.77

- Add a Woven OTP transport that maps Drop verification messages to the
  supported `POST /api/v1/messages` automation contract.
- Make the Woven installation base URL and server-side API token configurable
  through `SMS_API_BASE_URL` and `SMS_API_TOKEN`.
- Preserve the existing generic HTTP and development-only console transports;
  no data migration is required.
- Woven requests remain approval-gated by the upstream service and must be
  approved there before the connected phone sends the OTP.
- Add a persisted, superadmin-only OTP bypass test mode covering every
  phone-protected activity. Changes require a reason, are audited, and trigger
  a site-wide warning while bypass is active.
- Document the canonical hosted verification target and prohibit automatic use
  of local Docker Desktop unless the user explicitly requests it.
