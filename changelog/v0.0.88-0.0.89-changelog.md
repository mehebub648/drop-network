# Drop Network 0.0.89

## Changed

- Made donation totals deterministic as preserved pre-history donations plus
  the number of private detailed records.
- Added private donation notes and optional links to mutually confirmed Drop
  requests.
- Added an explicit, review-first donation story draft flow with optional
  selected public details and image.
- Added stable public story metadata plus native, WhatsApp, Facebook, and
  copy-link sharing.

## Compatibility and migration

- Existing lifetime totals are preserved on startup. The migration is
  additive and restart-safe; no detailed history or community media is removed.
- Existing `donation_count` remains in API responses as the derived total.
