# v0.0.48 to v0.0.49

## Changed

- Replaced the basic operations page with a responsive, capability-aware admin
  workspace for members, requests, reports, support, partners, imported claims,
  audit history, and safe system status.
- Added audited member suspension/reactivation, staff-role management, and
  session revocation with mandatory reasons.
- Enforced moderator, administrator, and superadmin capabilities on every admin
  route, including hierarchy, self-action, and last-superadmin protections.
- Kept the overview responsive while a large legacy imported archive is
  receiving its one-time public-ID backfill.

## Compatibility and security

- Legacy operational roles are migrated to the staff-role hierarchy at startup.
- Admin system responses expose operational status only; secrets, password
  hashes, OTPs, and session tokens are not returned.
